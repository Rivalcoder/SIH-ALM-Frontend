# **App Name**: Acoustic Insights

## Core Features:

- Audio  Upload and Processing: Allow users to upload various audio file formats for analysis.
- Speech and Non-Speech Analysis: Process audio to differentiate between speech and non-speech elements (background noise, music, etc.).
- Speaker Identification: Identify and differentiate between multiple speakers in the audio.
- Emotional Tone Detection: Analyze audio to detect emotional tones present in the speaker's voice.
- Generative AI Chat Tool: Enable users to ask questions about the audio analysis results via a chat interface, with answers powered by a generative AI tool.
- Result Visualization: Display the findings from audio analysis (speaker count, background sounds, emotional tone) on the frontend in a clear format.
- Light and Dark Mode: Support both light and dark modes for user interface customization.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a modern and intelligent feel.
- Background color: Light grey (#F5F5F5) for light mode, dark grey (#333333) for dark mode.
- Accent color: Teal (#009688) to highlight interactive elements and key data points.
- Body font: 'PT Sans', a humanist sans-serif font providing a blend of modernity and warmth for easy readability.
- Headline font: 'Space Grotesk', a proportional sans-serif, suitable for short bursts of text, like headlines.
- Use minimalist, animated icons to represent various audio features and functionalities.
- Incorporate smooth, attractive page transitions and loading animations to enhance the user experience.
- Design a landing page with animated feature cards that dynamically present project functionalities.
